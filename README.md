# Architecture InsureTech

Проектная работа 8 спринта - Архитектура ПО для InsureTech

## Описание проекта

InsureTech - компания, предоставляющая агрегационные услуги в сфере страхования. Проект направлен на решение проблем масштабируемости, производительности и надежности приложения.

## Структура проекта

Проект состоит из 6 заданий, каждое из которых находится в отдельной директории:

- `Task1/` - Задание 1
- `Task2/` - Задание 2
- `Task3/` - Задание 3
- `Task4/` - Задание 4
- `Task5/` - Задание 5
- `Task6/` - Задание 6

## Компоненты приложения

- **core-app** - монолитное бэкенд-приложение
- **client-info** - сервис управления клиентскими данными
- **ins-product-aggregator** - сервис интеграции со страховыми компаниями
- **ins-comp-settlement** - сервис взаиморасчётов со страховыми компаниями
- Веб-приложение для клиентов

## Технологии

- Kubernetes
- PostgreSQL
- REST API
- Nginx
- OpenAPI (Swagger)
- GraphQL
